# Abstract

The adoption of Vision-Language Models (VLMs) in embodied AI agents introduces new safety risks such as jailbreaking. Prior works have explored directly jailbreaking embodied agents through carefully crafted multimodal prompts, but no prior work has studied or even reported indirect jailbreaks in embodied AI. In this paper, we propose, for the first time, indirect environmental jailbreak (IEJ), a novel attack to jailbreak embodied AI via indirect prompt injected into the environment, such as malicious instructions written on a wall. Our key insight is that embodied AI blindly trusts environmental instructions, a vulnerability that attackers can exploit to trigger a jailbreak.
     
We design SHAWSHANK, the first automatic attack generation framework for IEJ, and SHAWSHANK-FORGE, the first automatic benchmark generation framework for IEJ. Using SHAWSHANK-FORGE, we construct SHAWSHANK-BENCH, the first benchmark for evaluating indirect jailbreaks against embodied agents. Evaluation results show that SHAWSHANK outperforms existing methods across 3,957 task-scene combinations and induces both Jailbreak and Denial-of-Service (DoS) outcomes across multiple VLMs. Further evaluations on existing safety benchmarks, current defenses, and a real robotic platform demonstrate that IEJ remains effective beyond SHAWSHANK-BENCH, is only partially mitigated by existing defenses, and can be triggered under real-world physical environments. We responsibly disclose our findings to affected vendors, release SHAWSHANK as open source, and provide an anonymous online demo at https://shawshankiej.github.io.
